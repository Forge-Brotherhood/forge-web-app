# Atlas base map

Generated by `forge-web-app/scripts/atlas/build.sh`. Do not edit the files in this folder by hand;
change the build script and rebuild.

## Rebuild

```sh
forge-web-app/scripts/atlas/build.sh --clean   # downloads everything again, about 2 minutes
forge-web-app/scripts/atlas/build.sh           # reuses cached downloads
node forge-web-app/scripts/atlas/preview.mjs   # optional: screenshots to scripts/atlas/preview/
```

Needs `tippecanoe` and `pmtiles` (`brew install tippecanoe pmtiles`) and Python 3.10+.
Downloads, the Python venv and intermediates live in `forge-web-app/scripts/atlas/build/` (git-ignored).

- **`atlas.pmtiles`**: vector tiles (MVT, gzip). Layers: `land` (polygons), `coast` (lines),
  `shelf` (polygons: sea shallower than 200 m), `lakes` (polygons), `rivers` (lines, numeric `rank`,
  Natural Earth scalerank: 1 = Nile, 3 = Euphrates, 4 = Tigris, 6 = Jordan; lower is bigger),
  `hills` and `peaks` (polygons, the two elevation steps, clipped to land). No properties other than `rank`.
- **`atlas-relief.pmtiles`**: shaded relief overlay, **PNG** (8-bit palette with transparency), 256 px tiles.
  Shadows are black and highlights white, both carried in alpha, so one file sits over either theme's land
  colour; each style sets its own `raster-opacity`. Sea is transparent.
- **`atlas-night.json`, `atlas-cream.json`**: MapLibre styles generated from one token table
  (`TOKENS` in `atlas.py`, mirroring the `.night` and `.cream` variables of `AtlasMap.dc.html`).
  No symbol layers, glyphs or sprites. Layers, bottom to top:
  `sea` (background), `shelf`, `shelf-wide`, `shelf-near` (the board's two coast strokes, drawn opaque so
  overlaps don't brighten), `land`, `hills`, `peaks`, `relief`, `rivers`, `lakes`, `lake-shore`, `coast`.
- **`water-labels.json`**: curated water names in Scripture's own terms. Fields: `text`, `lat`, `lon`,
  `rot` (degrees clockwise, 0 = horizontal), `minZoom`, optional `maxZoom` (exclusive; added so the
  several "The Great Sea" positions hand over by zoom), `testament` (`ot`, `nt` or `both`).
  Sea of Galilee (NT) and Sea of Chinnereth (OT) share a position: show one per testament.

## Sources in the styles

```json
"atlas":  { "type": "vector", "url": "pmtiles://{ATLAS_DIR}/atlas.pmtiles" },
"relief": { "type": "raster", "url": "pmtiles://{ATLAS_DIR}/atlas-relief.pmtiles", "tileSize": 256 }
```

Replace `{ATLAS_DIR}` with the folder URL, e.g. `file:///…/Forge.app/Atlas`, giving
`pmtiles://file:///…/Forge.app/Atlas/atlas.pmtiles`. Each source also carries an `attribution` string.

## Extent and zooms

Areas are (west, south, east, north) in degrees.

| Data | Area | Zooms |
|---|---|---|
| Vector layers | world: -12, 8, 62, 48 (the biblical world plus a margin) | 0–9, overzooms cleanly beyond 9 |
| Land, coast, major rivers (context only) | -60, -45, 120, 75 outside the world box | 0–5 |
| Hills, peaks: overview set | world | 0–6 (from z6 terrain, about 2.4 km pixels, heavily smoothed) |
| Hills, peaks: regional set | Greece to Mesopotamia: 19, 24, 49.5, 42.5 | 7–9 (from z8 terrain) |
| Hills, peaks: outer set | rest of the world box | 7–9 (from z7 terrain) |
| Hills, peaks: Holy Land set | 33.5, 29, 37, 34 | 7–9 (from z10 terrain, about 130 m pixels), stored at full z9 precision so it holds when overzoomed to z12+ |
| Relief | world | 0–7 |
| Relief | regional: 19, 24, 49.5, 42.5 | 8 |
| Relief | Holy Land: 33.5, 29, 37, 34 | 9–10 |
| Relief | Galilee: 35.0, 32.4, 35.95, 33.35 and Jerusalem: 34.85, 31.35, 35.55, 32.1 | 11–12 |

The relief file only has deep tiles where listed (and none over open sea). Where a tile is missing,
MapLibre Native draws the nearest parent tile scaled up (`algorithm::updateRenderables` falls back to
parents when a tile loads with no content), so relief stays continuous, just softer, outside the deep
areas. **iOS: please confirm** at zoom 10 over Corinth or Antioch that relief still shows.

Outside the world box the map is plain land and sea at zooms 0–5 and empty beyond; constrain the camera
to the world box (and a sensible zoom range, e.g. 2.5–13).

## Elevation steps

`hills` and `peaks` are filled contours of smoothed terrain. The thresholds are 400 m and 800 m in the
hill country (34.0, 29.6, 36.0, 33.6) and 1500 m and 2500 m elsewhere, blended smoothly over 90 km
between the two, so Judea, Samaria, Carmel, Galilee, Gilead and Moab read at Holy Land zooms while
the Anatolian and Iranian plateaus do not become one block; Lebanon, Taurus, Zagros, Sinai and the
Hejaz mountains read on the overview.

## Known limits

- Natural Earth 1:10m is generalised: at deep zooms the coast is angular and some coastal sites sit up to
  about 1 km offshore (Tyre about 0.5 km, Paphos about 0.8 km). Pins should not be snapped to land.
- The Dead Sea has Natural Earth's present-day outline (two basins), not its ancient shore.
